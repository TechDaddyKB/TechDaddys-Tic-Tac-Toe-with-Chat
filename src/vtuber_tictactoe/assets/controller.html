VTube Studio setup
  1. Install the HTML into VTube Studio’s Items folder (or another folder).
  2. Add a Web Item and enable local file access in its settings.
  3. Use the selected file’s full path as the Web Item URL, or drag the HTML into VTube Studio.
  4. Use a roughly 900 × 1024 viewport, turn on transparency, then position and pin the item.

Hiding keeps the Web Item loaded and does not pause the game. Use Pause voting separately. Preview also counts as an active HTML item.
